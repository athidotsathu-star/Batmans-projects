# Batman Bug Hunter public website

The static website lives in `public-site/`. It is separate from the Flask scanner and does not expose scanning endpoints.

## Cloudflare Pages settings

Connect the existing GitHub repository `athidotsathu-star/Batmans-projects` using Cloudflare Pages Git integration.

Use these settings:

- Project name: `batman-bug-hunter` (if available)
- Production branch: `main`
- Framework preset: `None`
- Root directory: repository root (leave blank)
- Build command: leave blank (no build step)
- Build output directory: `public-site`

After deployment, Cloudflare will assign a `*.pages.dev` URL. Future commits to `main` will trigger deployments automatically.

Official guide: https://developers.cloudflare.com/pages/get-started/git-integration/

## Google AdSense preparation

Ad slots are visual placeholders only. No ad scripts, publisher IDs, or fabricated `ads.txt` entries are included.

After the site is deployed:
1. Add the actual deployed domain to the Sites page in your AdSense account.
2. Complete Google's ownership verification using the exact code or meta tag AdSense provides.
3. Request review only after the site has substantial original content, working navigation, privacy information and a good user experience.
4. Once approved, add the official AdSense script and publisher-specific ad units to the reserved ad placements.
5. Publish the exact `ads.txt` record generated by AdSense. Do not guess the publisher ID.
6. Implement an appropriate consent solution for visitors in jurisdictions where consent is required before personalized advertising cookies or similar technologies are used.

AdSense approval is not guaranteed. A new site may need more original content and quality improvements before it is eligible.
